Trei benzi. Prima este ce rulează la demo: ecranul operatorului pe portul 8001 vorbește cu API-ul agentului pe 8000, iar API-ul folosește modelul, garda și jurnalul. A doua este drumul offline de la date la model: descărcare și profiluri, etichete din fluxul de putere, antrenare, modele salvate în artifacts și evaluarea cu un singur script. A treia este livrarea: la fiecare merge în main, GitHub Actions rulează testele, apoi Docker și Terraform pun aplicația în Azure Container Apps. Cloud-ul este o implementare, nu o dependență: juriul poate rula totul local din README cu make smoke și make test.
