Three lanes. The first is what runs at the demo: the operator screen on port 8001 talks to the agent API on 8000, and the API uses the model, the guard and the log. The second is the offline path from data to model: download and profiles, labels from the power flow, training, models saved in artifacts, and evaluation with a single script. The third is delivery: on every merge to main, GitHub Actions runs the tests, then Docker and Terraform put the app on Azure Container Apps. The cloud is a deployment, not a dependency: the jury can run everything locally from the README with make smoke and make test.
